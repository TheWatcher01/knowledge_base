           Les objectifs
                    Les objectifs de ce projet sont:
                          Savoir prendre les bonnes décisions de maquettage et appliquer un design responsive
                          en cas de besoin.
                          Découvrir quelques outils de maquettage et comment les utiliser.
                          Comprendre le design responsive, comment l'appliquer avec et sans une technologie
                          CSS comme bootstrap ou autre.
                          Savoir faire les bons choix techniques pour son projet.
                          Se préparer aux justifications des choix techniques prises avant le développement.
                          Se préparer pour les questions / réponses quand au passage des jurés RNCP.
