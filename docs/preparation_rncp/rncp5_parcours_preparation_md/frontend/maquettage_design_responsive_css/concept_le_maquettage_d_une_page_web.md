## Le maquettage d'une page web

### 1. Définition

Le maquettage est l'élaboration de représentations visuelles d'un produit, tel qu'une application ou
un site web, avant sa production finale. Il sert à planifier et à visualiser la structure, la
disposition et les fonctionnalités envisagées.

### 3. Avantages

- **Visualisation anticipée** : Permet d'apercevoir le produit final avant le début du
  développement.
- **Meilleure communication** : Facilite la collaboration entre les équipes et les parties
  prenantes.
- **Identification précoce des problèmes** : Aide à repérer et corriger les erreurs potentielles dès
  le début.
- **Économies de temps et de coûts** : Réduit les modifications coûteuses pendant le développement.
- **Optimisation de l'expérience utilisateur** : Permet d'ajuster la conception pour améliorer
  l'ergonomie et la satisfaction des utilisateurs.
