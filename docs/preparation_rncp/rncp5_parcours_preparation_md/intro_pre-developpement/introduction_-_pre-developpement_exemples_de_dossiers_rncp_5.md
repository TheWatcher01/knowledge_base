           RNCP 5 - Introduction - Pré-développement


           Introduction
           Dans le cadre de préparation et de développement d'une application, il est impératif de bien définir :

                    L'idée de son projet
                    Ses périmetres
                    Ses fonctionnalités
                    Pour qui ?
                    La méthodologie de travail
                    La conception (BDD avec Merise, Diagramme UML, architecture de l'application..)
                    L'environnement de travail (humain et technique)
                    Les technologies choisies
                    Les tests (quels types de tests ? avec quels outils ? et comment?)

           Ce qu'on doit savoir faire / avoir comme bagages pour le RNCP 5



                    Des connaissances en développement frontend:
                         Design Responsive
                               Il faut savoir comment faire des pages responsives avec flexbox, grid et media
                               queries
                         Accessiblité
                               Il faut savoir ce qu'est l'accessibilité
                               Comment rendre son site accessible
                               Avoir des connaissances techniques de base
                               Mettre en place certaines règles d'accèssiblité dans son application OU au
                               moins savoir comment le faire
                               On n'est pas obligé de maitriser le sujet mais on doit avoir des connaissances de
                               base
                         SEO
                               On doit savoir ce qu'est le SEO
                               Savoir comment appliquer certaines règles communes de SEO (et les appliquer
                               si possible).
                               On n'est pas obligé de maitriser le sujet mais on doit avoir des connaissances de
                               base
                         HTML, CSS, manipulation de DOM, JS
                         Comment tester son application avec les devtools du navigateur



                    Des connaissances en développement backend:
                         Développement d'une API:
                                Ce qu'une API
                                Ce qu'est une API REST
                                Comment tester son API avec Postman ou autre outil comme insomnia ou
                                autre…
                                Comment développer une API propre et sécurisé
                         Développement de la BDD:
                                Création d'une BDD avec du code SQL et / ou NoSQL (focus sur le SQL dans
                                tout les cas)
                                Sécuriser sa BDD contre les injections SQL
                                Savoir comment la rendre évolutive (scalability)
                                Savoir tester sa BDD (test manuel ou automatisés…)
                         Architecture:
                                Bien comprendre et maitriser l'architecture de son application
                                Savoir ce qu'une architecture MVC, le rôle de chaque composant et la relation /
                                liaison entre le C, le M et le V
                         Autre:
                                Développer des composants métier coté serveur (Business Logic componants)
                                Savoir ce qu'est un composant métier
                                Déployer son application OU au moins savoir comment le faire

           Ce qu'on n'est PAS obligé de savoir / faire pour le RNCP 5
                    La conception d'une BDD avec la méthode Merise
                          La personne qui va passer le RNCP 5 doit savoir lire et comprendre un ERD ou le MLD
                          de Merise et savoir l'implémenter en code.
                          Au cas où on n'a pas de diagramme déjà fait pour l'implémenter en code, on doit faire
                          un diagramme et dans ce cas là un ERD avec son implémentation en code sont
                          suffissants.

                    Les diagrammes UML

                    La gestion d'équipe
