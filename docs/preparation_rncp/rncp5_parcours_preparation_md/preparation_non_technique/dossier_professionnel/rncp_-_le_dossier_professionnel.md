            RNCP - Le dossier

               📁       Pour finaliser vos dossiers pour le jour J, vous devez préparer
                       le dossier professionnel (qui est complété par un livret d’évaluation
                       réalisé par l’équipe campus ainsi que vos relevés de scores Holberton
                       afin d’attester de vos compétences).



            Pour cela, vous pouvez utiliser le template du curriculum, avec quelques idées
            qui y sont intégrées pour le compléter.
            Le but est d’avoir un document support pour l’entretien final avec le jury et de
            justifier les compétences du titre (encore et toujours) en complément de votre
            projet présenté.
            ⚠️ Il est important d’avoir au moins 1 exemple par activité titre.
            🚀Conseil : si vous sentez que votre projet est léger sur une des compétences
            du titre (et que le jury risque de creuser), c’est dans ce Dossier Professionnel
            que vous pourrez compléter avec par exemple vos portfolios de fondamentaux,
            vos éventuels stages, ou tout projet Holberton pertinent (ex : HBnB ou Tests... ).
            Le meilleur complément à ce support reste votre github, donc assurez-vous
            que les projets pertinents de votre github soient accessibles le jour J !  ✅
            TRÈS IMPORTANT : Complétez bien la déclaration sur l’honneur.
            Une fois terminé, vous pouvez l’envoyer en pdf à votre équipe campus.
            Enfin, quelques ressources pour vous aider à compléter ce doc :

                 le guide officiel

            Planifiez-vous une journée pour le compléter sérieusement, et surtout
            choisissez judicieusement ce que vous y mettez.
            À très bientôt!!      ❤️
