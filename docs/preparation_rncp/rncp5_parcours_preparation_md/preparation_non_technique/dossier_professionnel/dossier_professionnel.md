           RNCP - Préparation non-technique - Dossier Professionnel


           Clarification
                    Ce projet constitue le troisième point de préparation non-technique pour le RNCP 5 ou le
                    RNCP 6.
                    Ce projet vous prépare à la rédaction du DP (Dossier Professionnel).

           Pour finaliser vos dossiers pour le jour J, vous devez préparer le **dossier professionnel** (qui est
           complété par un livret d’évaluation réalisé par l’équipe campus ainsi que vos relevés de scores
           Holberton afin d’attester de vos compétences).
           Pour cela, vous pouvez utiliser le template du curriculum, avec quelques idées qui y sont intégrées
           pour le compléter.

           Le but est d’avoir un document support pour l’entretien final avec le jury et de justifier les
           compétences du titre (encore et toujours) en complément de votre projet présenté.
